## 一、先认准官网入口：只有两个

**grok.com**：xAI 的独立网页版，邮箱或 Google 账号直接注册，**不需要 X（推特）账号**。这是国内用户最省事的入口，也是充值时要填的账号。

**x.com 里的 Grok 标签页**：需要 X 账号，且这里的 Grok 权益来自 X Premium+，和 SuperGrok 不是一回事（见下节）。

搜索结果里排在前面的各种「grok 官网入口」导航站，多数只是跳转页，有的会把你引到山寨登录页收密码。认准这两个域名，别的一律不要在上面输密码。

| **SuperGrok Heavy** | $300/月 | 多智能体并行推理、最高优先级与用量 | grok.com |

一句话：**冲着 Grok 模型本身去的，买 SuperGrok**，它反过来还附带 X Premium+ 的权益；单买 X Premium+ 是为了蓝标和推文功能，Grok 额度只是顺带。

Heavy 是 10 倍价格换多智能体模式和最高优先级，只有把 Grok 当生产力主力、每天跑大量并行任务的人用得上。绝大多数人 SuperGrok 就是天花板。

## 三、国内为什么付不了款

grok.com 的收款由 Stripe 处理，只接受境外发行的 Visa / Mastercard，且账单地址需与发卡地一致。国内储蓄卡、银联卡、绝大多数双币卡都会被拒；支付宝、微信、PayPal 官方均不支持。

这和 ChatGPT、Claude 撞的是同一堵墙，是发卡地规则，与你的余额、征信、操作都无关。

注意 Grok 没有官方的 App Store 内购路径（不像 ChatGPT 和 Claude），所以国内实际可选的只有这三条。

1. 先在 **grok.com** 用邮箱或 Google 账号注册好自己的账号，登录一次确认能正常使用

Grok 的充值比 ChatGPT Pro 还省一步：不需要临时凭证授权，只要邮箱。所以任何以"充值需要"为名索要密码或验证码的，都不是正规做法。

## 八、FAQ

**Q：没有 X（推特）账号能用 Grok 吗？**
能。grok.com 支持邮箱或 Google 账号直接注册，SuperGrok 也是在 grok.com 订阅，全程不需要 X 账号。

**Q：Grok代充会导致封号吗？**
走官方订阅通道、充到你本人账号的，在 xAI 侧与官网直付没有区别。被封的是共享账号和用盗刷卡开的号。

**Q：SuperGrok 和 Heavy 怎么选？**
先 SuperGrok。Heavy 的多智能体模式和最高优先级，只有每天跑大量并行任务的人才用得上。

**Q：Grok 和 ChatGPT 该买哪个？**
实时资讯、X 平台内容分析选 Grok；写作、长文档分析、代码选 ChatGPT 或 Claude。都想要的先各买最低档试一个月。

**Q：充值后额度什么时候重置？**
按订阅周期与官方的滚动窗口计算，具体以 grok.com 账户页显示为准。
